# TravelOS 配樂準則

配樂依地點、季節、當時情緒、畫面速度及原聲決定。先看短片再選音樂，不只搜尋國名或套用熱門曲。每篇先寫一行畫面描述與一行音樂方向，再一起播放審聽。

## 已確認的方向

- 芬蘭聖誕老人村冬季雪景：舒緩、溫暖或低沉，有空間感，配合雪地與冬夜。避免輕快跳躍、明顯夏日舞曲感的人聲或節奏。聖誕氣氛不等於每段都必須熱鬧。
- 日本篇：Owner 提供玉置浩二、鈴木常吉為參考。選曲可參考沉靜、有人情味的人聲與敘事氛圍；具體喜好仍以 Owner 對實際畫面與音樂的反應為準。京都楓葉需支撐秋日色彩與漫步節奏，不掩蓋環境聲。

## 選曲與交付

1. 先辨識畫面：季節、白天或夜晚、行走或停留、熱鬧或安靜，以及家人對此段的真實情緒。
2. 為重要片段準備少量候選，實際配入相同畫面比較開場、轉場與結尾；不要讓剪輯為音樂硬改成不符經歷的氣氛。
3. 有對話時降低配樂，值得保留的腳步、風雪、街聲應聽得到；手機喇叭也要審聽。
4. 公開與社群版只用具備對應使用權的音樂，記錄曲目、來源、授權範圍及需要的署名。提到歌手只是美感參考，不表示其作品可用，也不要求仿製嗓音或旋律。
5. 保留無配樂母版與可替換配樂，方便不同平台使用。未確定授權的候選不能當成可公開成品。

驗收問題：閉眼聽是否像同一季節與情緒？睜眼看是否支持畫面？有沒有蓋過家人的聲音？Owner 是否覺得像這趟旅行？先修正不合適的配樂，再擴用到其他篇。
