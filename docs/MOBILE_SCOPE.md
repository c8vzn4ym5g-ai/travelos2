# 手機與 notebook 的功能界線

Owner 決定：2026-09-13。這是驗收範圍，不是已完成聲明。

| 使用情境 | 必須能做 | 可接受的限制 |
| --- | --- | --- |
| 旅行途中，notebook 關機 | 手機上傳原始照片、影片、語音；補一句文字；歸入旅程；雲端保存 | 不要求手機完成精細剪片或大量排版 |
| 回家後只拿手機 | 看最新內容、改字、補照片、簡單選圖與保存 | 不需要先打開 notebook 或 Obsidian |
| 夫妻不同装置 | 讀寫同一份雲端旅程，保存結果可見；遇到另一人的新修改保留自己的草稿 | 不要求即時協同逐字編輯；不可無提示覆蓋另一人的更新 |
| notebook 整理 | 大批素材核對、長篇整理、精細剪片、Obsidian 深入編輯 | 可依賴 notebook 開機 |
| Obsidian | 與既有 JDB-Runtime 的 TravelOS 專案銜接，保留可讀文稿 | 首階段單向私人鏡像；不承諾全功能雙向同步 |

所有日常手機操作均不得以本機檔案路徑、本機服務或 Obsidian 開啟作為必要條件。上傳原檔與顯示用縮圖分開；缺少拍攝資訊不妨礙收件。首頁不應為展示旅程卡片先載入全部照片與正文。

先完成上述日常流程，再擴充低頻重度功能。既有公開／私人選擇維持，圖片與家人記憶不得憑空補造。
