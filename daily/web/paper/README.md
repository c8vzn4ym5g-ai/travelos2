# Shared paper-card assets

Three reusable transparent PNG backings generated once with the built-in ChatGPT image_gen tool, then resized to256px and palette-packaged locally with no API key or extra service. No household content was provided. New notes only reuse cached assets; text remains DOM. Total91,441 bytes. Original outputs are preserved locally under daily/scratch/paper-sources; only optimized card PNGs are served.

Prompt set: one top-down, upright nearly-square handmade watercolor paper card; real transparent exterior/tight3% margin; naturally irregular deckled edges; visible fibers/cold-press grain; clean central80–85% for dark live handwriting; no text/logo/watermark/lines/tabletop/tape/pins; pale honey/ivory or pale sage edge wash. Flower variant adds tiny muted sage/peach wildflowers solely in the lower-right corner under7% of paper area; other two are blank paper. Rotation is CSS-only. No per-entry generation or external image service.

Packaging: generated original RGBA PNGs -> built-in System.Drawing high-quality256px resize -> daily/optimize-paper-png.py standard-library indexed PNG optimization retaining transparency. Original procedural textures were not selected and are not served.
